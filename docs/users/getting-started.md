# Getting started with LicenX

**Who is this for?** First-time system owners, administrators, and software distributors. For deployment commands and prerequisites see [Installation](installation.md).

## First-owner onboarding

1. Install using the reviewed VPS installer and configure HTTPS; open `https://YOUR_DOMAIN/vcon`.
2. If no administrator exists, the UI displays **VCON Server Setup**. On a PostgreSQL VPS, enter the one-time owner setup code generated by the installer. Supply a username, master password and confirmation; password length must be at least 12 characters. Optional R2 configuration can be entered at setup.
3. After setup, sign in with the chosen admin account. Do not use a supposed default production password.
4. Open **Applications** and create a named application with its slug and minimum client version.
5. Open **License Keys** or **Issue Key** to create a scoped license. Copy its license key and separate four-digit PIN only into a secure delivery channel.
6. Integrate the supported Python `licenx` client with the registered app version and the trusted server public key. See [Python SDK](features/python-sdk.md).
7. Use **Live Validator** only with a test key: it can invoke validation and device binding; it is not a passive health probe.

## Admin navigation

The sidebar organizes **License Engine**, **Client Integration**, **Administration** and **Public** groups. Actual tab labels and their page paths are listed in [Administration](features/admin-console.md); `src/App.tsx` stores current tab preference in browser storage.

## License-holder access

The public portal supports a status check with a license key and a separate PIN-protected device control. These have different validation and security implications. See [Public portal](features/public-portal.md).
