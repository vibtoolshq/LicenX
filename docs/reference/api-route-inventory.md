## Special registration and caveats

- The restricted partner membership checker is registered as `apiRouter.all(PUBLIC_LICENSE_CHECK_PATH)` in `src/server/api.ts`; its canonical path constant is `/v1/public/license/check`, with **POST** allowed and method/Origin restrictions enforced by `src/server/restrictedPublicLicenseCheck.ts`.
- `src/server/api.ts` also registers array-path public asset aliases `/public/assets/*` and `/storage/file/*`. They are accessible through the canonical `/api` mount and follow the storage proxy authorization logic.
- `server.ts` additionally mounts the `apiRouter` on `/v1` as a compatibility layer, and intercepts unknown API requests. Do not treat all combinations as independent documented endpoints.
- The optional websocket upgrade paths `/api/realtime` and `/api/admin/realtime` are **not HTTP REST registrations** and are documented in [Realtime](../users/features/realtime.md).
- The table is an inventory of declarations. Sensitive handlers require admin session, API key, PIN, ticket or other enforcement. Review [API contracts](../dev/api-reference.md) and code before making requests.
