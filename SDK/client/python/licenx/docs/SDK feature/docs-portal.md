# SDK Documentation Portal

Source: `SDK/client/python/licenx/docs/README.md`

This portal links the packaged English and Bangla integration guides. It contains **no standalone quick-start example or module responsibility table**; the package-level `README.md` provides the quick start. This `SDK feature/` directory is a **repository-only** source-level companion and is intentionally excluded from the wheel's declared package data and from the generated source ZIP.

The quick-start path depends on an actual application version being supplied and a valid trusted public key. Consult [configuration](config.md) and [transport](server.md) for those requirements; do not copy minimum-version policy into the client version field.
