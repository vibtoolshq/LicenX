# LicenX Python SDK Documentation

This directory is packaged with the **primary `licenx` Python SDK** at `SDK/client/python/licenx/`.

- [English guide](GUIDE_EN.md)
- [বাংলা guide](GUIDE_BN.md)
- [Source and feature map](SDK%20feature/README.md)
- [Primary package README](../README.md)

The recommended integration is `from licenx import XLicenseClient` using the app-root `licenx.config.py`. Online validation, a trusted public key and an explicit running `app_version` are required. The legacy `SDK/x_license_python` implementation remains reference-only; the existing `x_license_python.zip` is not the primary package distribution.
