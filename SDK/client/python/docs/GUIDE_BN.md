# LicenX Python SDK — বাংলা গাইড

**একটি supported SDK:** `licenx`। Config: `licenx.config.py`; install: verified wheel অথবা primary source kit।

নতুন integration-এর **primary package** [`licenx`](../licenx/README.md)। Repository root থেকে `python -m pip install ./SDK/client/python/licenx` install করুন এবং `from licenx import XLicenseClient` import করুন।

**[সম্পূর্ণ বাংলা integration guide](../licenx/docs/GUIDE_BN.md)**-এ app configuration, trusted signature, login, heartbeat, logout, version policy ও security ব্যাখ্যা আছে।
