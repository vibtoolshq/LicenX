# LicenX Python SDK — English Guide

The maintained **primary** package is [`licenx`](../licenx/README.md), imported as `from licenx import XLicenseClient`. Install it with `python -m pip install ./SDK/client/python/licenx` from the repository root.

**[Open the complete English integration guide](../licenx/docs/GUIDE_EN.md)** for configuration, signed login, heartbeat, logout, restrictions and safety guidance.

Also see [API reference](API_REFERENCE.md) and [configuration](CONFIGURATION.md). The older `SDK/x_license_python` tree is reference-only, and its `x_license_python.zip` is not a primary `licenx` installer.
