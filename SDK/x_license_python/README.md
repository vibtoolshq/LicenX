# Reference Python SDK — `x_license_python`

**Reference/compatibility implementation only.** This source tree is retained for regression testing, older integrations and the current reference ZIP archive. It is **not** the primary Python SDK recommended for new LicenX applications.

For a new application use **[`SDK/client/python/licenx`](../client/python/licenx/README.md)** instead:

```bash
python -m pip install ./SDK/client/python/licenx
```

```python
from licenx import XLicenseClient
```

## Reference usage and behavior

The reference source imports as `x_license_python` and retains its own config and test harness. It supports signed online license validation, HWID binding, heartbeat and logout, but must not be confused with the installable `licenx` distribution.

- [Reference English guide](docs/GUIDE_EN.md) · [বাংলা reference guide](docs/GUIDE_BN.md)
- [Reference test harness](test/README.md)
- [Primary SDK guide](../client/python/docs/README.md)

The archive generated by `scripts/buildPythonSdkArchive.mjs` remains `public/x_license_python.zip`. This is a **reference archive**; no server download behavior was changed in this documentation update.

### Basic Integration (reference/legacy only)

```python
from x_license_python import XLicenseClient, SDKConfig

config = SDKConfig.from_file("my_app_vcon_config.json")
client = XLicenseClient(config)
result = client.login("REFERENCE-TEST-KEY")
if not result.success:
    raise SystemExit(result.message)
print(f"License Activated! Tier: {client.get_tier()}")
print(f"Hardware ID: {result.hwid}")
```

### Manual Heartbeat & Logout

Use `client.ping()` and `client.logout()` for the reference API. Existing consumers may continue to use this module; **do not copy reference imports into new `licenx` integrations**. License keys must never be committed or printed in production logs.
